# Aligner Studio（ダイレクトプリント・アライナー設計 / 試作版）

口腔内スキャン（STL）・CBCT（DICOM）・フェイススキャン（OBJ）・側面セファロを読み込み、
歯を1本ずつ（歯根を含めて）分割し、セファロの目標値に向けて自動で排列し、
3次元的にステージングして、**LuxCreo などのダイレクトプリント用に水密なアライナー STL** を書き出すブラウザアプリです。

> ⚠️ 研究・試作用のソフトです。臨床で使う前に、精度検証（試作・適合確認）と、
> 医療機器プログラムとしての規制（日本では薬機法）の確認が必要です。

## 起動

ビルド不要です。ES モジュールと Web Worker を使うため、ローカルサーバー経由で開きます。

```bash
cd aligner
npm start            # = node tools/serve.js → http://localhost:8080/
```

Node.js がなければ `python3 -m http.server 8080` でも動きます（`aligner/` で実行）。
テストは `npm test`。

## 作業の流れ（画面左のタブ）

| タブ | 内容 |
|---|---|
| 1 取込 | 上顎/下顎 STL、CBCT（DICOM フォルダ）、フェイススキャン OBJ（＋テクスチャ）。**デモ症例**で全工程を試せます |
| 2 位置合わせ | **基準点で合わせる方式が基本**。①CBCT の骨で ANS・左右外耳道中央・N を指定 → **カンペル平面（ANS–左右外耳道中央）と正中矢状面**を作成し、表示をその座標系にそろえる。②口腔内スキャン ⇄ CBCT を名前付きの対応点（5点、3点以上で可）で合わせ、点ごとの誤差を表示。必要なら表面で微調整（対応点の誤差が悪化すれば不採用）。③顔スキャン ⇄ CBCT を軟組織の対応点で合わせる。点は CBCT の歯・骨・皮膚の立体や断面の上に打てる。自動合わせは参考機能 |
| 3 歯の分割 | 歯冠ごとにシードをクリック（FDI 番号は自動で次へ）→ **曲率にもとづくウォーターシェッド**で自動分割 → ブラシで手修正 → 歯モデル作成 |
| 4 歯軸・歯根 | 歯根長・太さ・抵抗中心・歯軸補正。**歯軸を通る CBCT 断面（頬舌・近遠心）**に歯の輪郭を重ねて確認 |
| 5 セファロ | 画像上で計測点を打つ → SNA/SNB/ANB/FMA/SN-MP/U1-SN/U1-FH/U1-PP/IMPA/切歯軸角/A-Pog。目標値を入力し「セットアップに反映」（切歯トルク変化、OJ/OB 目標） |
| 6 セットアップ | 歯列弓形態・拡大・前方移動・トルク・IPR 上限・大臼歯固定・レベリング・捻転除去・正中合わせ → **自動排列**。OJ/OB を目標へ合わせる機能あり |
| 7 ステージング | 1ステージの上限（並進・挺出・圧下・傾斜/トルク・捻転）と進め方 → **自動ステージング**。歯ごとの開始/終了、**中間キー**（任意のステージで歯を動かす）、上限超過の警告、IPR 時期、アタッチメント |
| 8 アライナー出力 | 隙間・厚み（均一 / 部位別）・トリム・ブロックアウト・平滑化・間引き → プレビュー → **全ステージを ZIP（STL＋CSV＋レポート）で書き出し** |

画面下のスライダー（←/→ キー）でステージを切り替え、▶ で再生。歯をクリックすると右パネルで
6自由度（近遠心・頬舌・挺出圧下・チップ・トルク・捻転）を数値や ± ボタンで編集でき、
**G / R キーで移動・回転ギズモ**が使えます。初期ステージ以外では、最終ステージの編集は目標位置、
途中のステージの編集は中間キーになります。

## 歯の動きの定義

各歯に座標系を持たせています：`m`＝近心方向（歯列弓の接線）、`b`＝頬側、`z`＝咬合方向（歯軸）。
回転は**抵抗中心（CR）**まわり（既定は歯頸部から根尖へ歯根長の 40%）。

| パラメータ | 意味 |
|---|---|
| md | 近遠心移動 (mm, ＋近心) |
| bl | 頬舌移動 (mm, ＋頬側) |
| ext | 挺出/圧下 (mm, ＋挺出) |
| tip | チップ (°, ＋歯冠が近心へ) |
| torque | トルク (°, ＋歯冠が頬側へ) |
| rot | 捻転 (°, ＋近心が頬側へ) |

## アライナー STL の作り方（`src/geom/shell.js`）

1. 各ステージの姿勢で、歯（歯冠＋推定歯根＝閉じた立体）・歯肉（歯に追従して変形）・アタッチメントを配置
2. 着脱方向（咬合方向）の柱ごとに交差回数で内外判定（アンダーカットも保持。ブロックアウトも選択可）
3. 表面からの**正確な距離**を狭帯域で計算 → 「隙間 c ≦ 距離 ≦ c＋厚み」の殻
4. 歯頸線から指定量だけ歯肉側でトリム（スカラップ状）
5. マーチングテトラヘドラで**水密・多様体**の面を作成 → Taubin 平滑化 → QEM 間引き（水密を保持）
6. 水密チェックの結果をレポートに出力。単位 mm のバイナリ STL

LuxCreo 側では、LuxCreo のソフトで配置・サポート付け・スライスを行ってプリントします。
厚み・隙間・トリム量は**初期値**です。材料とプリンターの推奨値、試作での適合確認で決めてください
（LuxCreo の資料には部位別の厚みの例として前歯 0.5 mm・臼歯 0.8 mm が挙げられています）。

## ファイル構成

```
aligner/
  index.html            画面（CSS 変数は :root と dark 用ブロック）
  src/app/main.js       画面とワークフロー（状態 S、各タブの処理、保存/読込）
  src/app/viewer.js     three.js ビューア（表示・ピック・ギズモ・CBCT 断面）
  src/app/shell.worker.js  シェル生成の Web Worker
  src/core/             ベクトル/行列、メッシュ（隣接・境界・平滑化・水密チェック）、QEM 間引き
  src/io/               STL / OBJ / DICOM（非圧縮）/ ZIP（無圧縮）
  src/geom/             位置合わせ（Horn・ICP）、歯牙分割、歯モデル（歯根・姿勢）、等値面、シェル
  src/plan/             歯のデータ（FDI）、歯列弓、顎モデル、セファロ、自動排列、ステージング・接触
  src/demo/demoCase.js  合成デモ症例
  vendor/               three.js r170（MIT, THREE_LICENSE）
  test/                 node:test による単体テスト
  tools/serve.js        簡易ローカルサーバー
```

プロジェクト保存（`*.alnproj.zip`）にはスキャン・分割ラベル・歯の設定・計画・セファロ・位置合わせ行列が入ります
（CBCT 本体は容量のため含めません。開いたあと DICOM を読み込むと位置合わせが復元されます）。

## 現時点の制約・今後の課題

- **歯根は推定形状**（平均歯根長の先細りの単根、歯頸部の形状から作成）。CBCT 断面を見て長さ・太さ・歯軸を調整できますが、
  CBCT からの歯根の自動セグメンテーション（複根を含む）は未実装
- 歯牙分割はシード（各歯1クリック）が必要。完全自動（AI）分割は未実装
- 自動排列は「歯列弓に沿って接触を詰める」方式。咬頭嵌合（上下の噛み合わせの最適化）は OJ/OB の概算合わせのみ
- 歯肉の変形は歯への追従（距離による重み）で簡易的
- DICOM は非圧縮のみ（JPEG/JPEG2000 圧縮は非対応）。セファロは画像（PNG/JPG）
- 歯の重なり量は「2本を結ぶ方向に必要なずらし量」で評価（IPR・スペースの目安）
- 全ステージの書き出しは1ステージあたり数十秒かかります（ボクセルを大きくすると速くなります）
